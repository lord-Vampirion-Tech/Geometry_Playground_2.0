
# Geometry Playground — Справка

Добро пожаловать в Geometry Playground!

Здесь можно создавать 2D- и 3D-объекты с помощью Python,
а также управлять их поведением во времени.

## 1. Создание объектов

### New_SQUAER()

Создаёт двумерный квадрат или прямоугольник.

```python
New_SQUAER(
    x=0,
    y=0,
    width=16,
    height=16,
    color="#42a5f5"
)
```

| Параметр | Описание       |
| -------- | -------------- |
| x        | Положение по X |
| y        | Положение по Y |
| width    | Ширина         |
| height   | Высота         |
| color    | Цвет объекта   |

Пример:

```python
New_SQUAER(
    x=0,
    y=0,
    width=32,
    height=32,
    color="#ff5252"
)
```

### New_CUBE()

Создаёт трёхмерный куб или прямоугольный параллелепипед.

```python
New_CUBE(
    x=0,
    y=0,
    z=0,
    width=16,
    height=16,
    depth=16,
    color="#42a5f5",
    opacity=1.0
)
```

| Параметр | Описание               |
| -------- | ---------------------- |
| x, y, z  | Положение объекта      |
| width    | Размер по X            |
| height   | Размер по Y            |
| depth    | Размер по Z            |
| color    | Цвет объекта           |
| opacity  | Прозрачность от 0 до 1 |

Пример:

```python
New_CUBE(
    x=0,
    y=0,
    z=0,
    width=16,
    height=32,
    depth=16,
    color="#42a5f5"
)
```

### New_BOUNDS()

Создаёт ограничивающий объём по минимальным и максимальным координатам.

```python
New_BOUNDS(
    minx, miny, minz,
    maxx, maxy, maxz,
    color="#42a5f5",
    opacity=1.0
)
```

Пример:

```python
New_BOUNDS(
    -16, 0, -16,
    16, 32, 16,
    color="#66bb6a"
)
```

## 2. Математика

Доступны стандартные математические функции Python из модуля `math`.

Их можно вызывать напрямую:

```python
sin(1)
cos(1)
sqrt(25)
radians(90)
degrees(1.57)
pi
```

Также доступны:

```python
math.sin(1)
math.cos(1)
math.sqrt(25)
math.pi
```

Дополнительные псевдонимы:

| Функция   | Аналог  |
| --------- | ------- |
| arccos(x) | acos(x) |
| arcsin(x) | asin(x) |
| arctan(x) | atan(x) |

## 3. Анимация

Для создания анимации необходимо объявить функцию:

```python
def update(Time):
    pass
```

Она автоматически вызывается каждый кадр, пока анимация запущена.

### Time

Текущее время анимации в секундах.

Пример движения объекта:

```python
def update(Time):

    x = sin(Time) * 50

    New_CUBE(
        x=x,
        y=0,
        z=0
    )
```

### loop()

Повторяет значение в заданном временном диапазоне.

```python
loop(value, duration, start=0.0)
```

| Параметр | Описание           |
| -------- | ------------------ |
| value    | Текущее значение   |
| duration | Длительность цикла |
| start    | Начало диапазона   |

Пример:

```python
def update(Time):

    x = loop(Time * 20, 100)

    New_CUBE(x=x)
```

## 4. Управление камерой

В режиме 3D доступны следующие действия:

| Действие                | Управление          |
| ----------------------- | ------------------- |
| Вращение камеры         | ЛКМ + движение мыши |
| Перемещение камеры      | СКМ + движение мыши |
| Приближение / отдаление | ПКМ + движение мыши |
| Приближение / отдаление | Колесо мыши         |
| Движение вперёд         | W                   |
| Движение назад          | S                   |
| Движение влево          | A                   |
| Движение вправо         | D                   |
| Движение вниз           | Q                   |
| Движение вверх          | E                   |
| Ускорение перемещения   | Shift               |

## 5. Управление редактором

| Действие         | Комбинация   |
| ---------------- | ------------ |
| Выполнить код    | Ctrl + Enter |
| Сохранить проект | Ctrl + S     |

Кнопка «Выполнить» запускает выполнение текущего кода.

Кнопка «Пауза» приостанавливает или возобновляет анимацию.

Кнопка переключения режима меняет отображение между 2D и 3D.
