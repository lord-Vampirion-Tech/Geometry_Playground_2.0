# Geometry Playground 2.0 — стартовый каркас

## Требования
- Windows 10/11
- Python 3.12

## Установка
```powershell
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск
```powershell
python run.py
```

По умолчанию проекты хранятся в папке `Projects` рядом с исполняемым файлом. Путь можно изменить в настройках менеджера. Настройки приложения хранятся в папке `Settings` рядом с исполняемым файлом.

## Структура
- `run.py` — точка входа.
- `app/settings.py` — настройки приложения (`Settings/settings.json` рядом с исполняемым файлом).
- `app/project_store.py` — создание, чтение и удаление проектов.
- `app/project_manager_window.py` — окно менеджера проектов и фоновая подготовка библиотек 2D/3D.
- `app/module_loader.py` — параллельная загрузка модулей режимов в фоне.
- `app/project_window.py` — пустое окно открытого проекта.

Проекты хранятся в `Projects` рядом с исполняемым файлом (или в выбранной пользователем папке). Каждый проект находится в отдельной подпапке с файлами `project.json` и `code.py`.


## API геометрии

Фигуры создаются конструкторами, соответствующими режиму проекта: в 2D доступны `Point`, `Line`, `Square`, `Polygon`, `Circle`; в 3D — `Point`, `Line`, `Cube`, `BoundingCube`, `Sphere`. Для отображения объекта вызовите `draw()`.

## Диагностика аварийного завершения

Ошибки Python и Qt записываются в журнал:

```
%LOCALAPPDATA%\ZifTech\Geometry Playground 2.0\crash.log
```

При необработанной ошибке программа показывает окно с этапом сбоя и подробностями. Для нативных аварий Qt/VTK/OpenGL, которые завершают процесс без возможности выполнить Python-код, в журнал записывается последний этап работы и стек, если его удаётся получить через faulthandler.
